# 听见日常 · 泰语听力练习

公开课程：https://liangqishan-ctrl.github.io/thai-learning/

- 第一季：`index.html`，保留原基础短句课程。
- 第二季：`season2.html`，保留原进阶短句课程。
- 第三季：`season3.html`，18讲、90篇趣味生活故事、180道题。
- 第四季：`season4.html`，18讲、90篇趣味生活故事、180道题。

新两季每讲5篇，每篇2道四选一题，含即时答案、原文、中文对照、重点构词拆解、常见词与口语结构、语速调整、逐词跟读、复制、错题复习和本机进度。每篇60—92个泰语词，附50—100字中文译文。泰语词数由 `Intl.Segmenter('th')` 的词语切分估算，不是用空格数或泰文字母数代替。所有故事均为原创虚构，用于语言练习；人物的玩笑和比喻不作现实事实解读。

网页为可查看和编辑的静态HTML，无账号、无后端、无第三方资源、无跟踪。第三／第四季各自是一个完整单文件，另存HTML后可继续使用。语音由设备的泰语朗读服务提供，不是预录音频；设备需要支持泰语语音。若无声，检查媒体音量、静音开关和系统语音设置。进度保存在当前浏览器，清理浏览器数据会清除进度；禁用存储时仍可在内存中练习。

## 修改与生成

原始故事在 `stories-*.txt`，词语表在 `glossary.txt`，页面模板在 `story-course.template.html`。运行：

```sh
python3 build.py
node verify.cjs
```

构建需要Python 3和支持 `Intl.Segmenter` 的Node.js。可用 `NODE=/absolute/path/to/node python3 build.py` 指定路径。构建不会改动第一、第二季题库。

生成器检查180篇内容独立、每篇2题4选1、词数与中文篇幅、重点词确实出现在原文中，以及答案位置轮换。额外的验证检查计分、错误答案、复习、刷新还原、跳转和存储不可用的降级行为。手机实际出声仍依赖设备。

本仓库使用已启用的GitHub Pages发布。默认分支内容更新后，由原有Pages构建流程更新公开网页。
